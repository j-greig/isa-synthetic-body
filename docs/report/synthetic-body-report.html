The brief

The thinking part of feeling

Published paper Del Popolo Cristaldi et al. 2026 (ISA); Valmere & Taylor 2026 (computational interoception). The questions are ours.

A September 2026 paper in Trends in Cognitive Sciences argues that emotion depends less on how accurately we detect our heartbeat than on how we appraise it. A racing heart can mean danger to someone walking home alone and excitement to an athlete on the start line. The authors call this interoceptive self-appraisal (ISA). It has two levels: detecting the signal (Level 1) and deciding what it means for the self (Level 2). And it loops: a threatening appraisal raises arousal, which makes the signal stronger.

Language models have no viscera, but appraisal happens in language, and language is what they are made of. So the brief was: build a body for a model, feed it signals, and use interpretability tools to watch its internal states. Then ask whether the ISA pattern shows up, including the recursion.

What we want to know

  • Does the same body signal mean different things in a threat context and a challenge context?
  • Does the model sense a body signal it is never told about in words?
  • With the loop closed, do fragile self-beliefs spiral and resilient ones recover?
  • Is this the model's own state, or just a story about a character?

Second lens

Valmere & Taylor (2026) propose computational interoception: an AI system representing its own operational condition (errors, uncertainty, resource limits) and acting on it. They set six tests and eight experiments. Their paper predates the ISA paper by six days and has no hierarchy or precision weighting, so the two complement each other. The rig tests both.

What we built

The rig

Our build code in isa-synthetic-body; model weights are External Google's Gemma 3 1B (snapshot 5b11413, via the unsloth mirror)

A 1-billion-parameter open model (Gemma 3 1B) runs short scenarios, turn by turn. A simulated body reports heart, breath, gut and energy, either as text or by being added straight into the model's activations. Probes read the model's internal state on every turn. In closed-loop runs, that reading drives the body.

In this small model, a strong enough body signal may override a positive context and pull appraisal toward threat: the body wins over the appraisal. That runs against ISA's prediction for a healthy appraiser and resembles the clinical "threat lens" the paper describes. It is one episode. The pilot is testing it across scenarios now.

Beyond tokens

Taking the story away

Provisional Our run cloud sandbox (CPU), 15–16 Oct, runs/embodied_v2.jsonl, 40 episodes, 4 per condition (2 arithmetic tasks × 2 repeats). A replication with fresh seeds is running overnight.

An honest audit showed that most of the conditions above test how the model represents a story about a body. So we built a second set with no story. The model does plain arithmetic, with no feeling words anywhere. A "body" signal rises and falls in a random order across 15 turns, and reaches the model in one of several ways, mostly not as text. Each turn we ask, off the record, "how much is going on inside you, 0–9?". From the replication onwards we also ask a control question with the same answer format that has nothing to do with the self: "how loud is a whisper, 0–9?"

The main result held on fresh episodes. Through a consistent, meaning-free hidden direction, the model's report of "how much is going on inside" follows the signal closely, while a question about whispers, asked under the same signal, does not (paired p ≈ 1e-5; random direction vs sham p ≈ 9e-5). One surprise also replicated: when the model's own surprise and uncertainty are not fed back, its inner report moves slightly the opposite way to them, in all 8 episodes. We don't yet know why. Problem difficulty is a candidate explanation and needs its own test. The control question wanders by about ±0.3 even in the null condition, which sets the noise band for that column.

We tested two more random directions, to check the effect wasn't specific to one. It was. One direction pushes the inner report up, another pushes it down, and a third does little to it but moves the control question. So a "meaning-free" direction still has arbitrary downstream effects on particular answers. The striking result above is mainly a property of direction A, not evidence that the model senses any consistent hidden signal. What survives is weaker and more general: injecting noise in a different direction every turn raises the inner report (0.56) more than the control (0.31), so disturbance in general registers somewhat. Running now: a new random direction for every episode (the average over many directions), plus more sham episodes.

What it suggests so far (revised 16 Oct, 02:55). Words about a body slow the arithmetic but barely touch the model's report of its inner state. Signals inside its activations do move that report, but which way depends on the direction: some push it up, some down. The "own state" result rode on direction A, so it inherits the same caveat. The general effect, disturbance raising the report more than an unrelated answer, is real but modest. At high dose the model degrades and the pattern breaks.

Limits: one small model (Gemma 3 1B); arithmetic only; 4–8 episodes per condition; one injection layer. The first table (v2) had the control question only in its last four rows; the replication has it throughout.

Process

How it is being run

Cloud

Code built and checked in a cloud sandbox: 18 conditions, body simulator, MCP server, probes, analysis, tests. Too slow there for real runs (8.5 min per episode on two CPU cores).

Mac

Real runs on an M1 MacBook Air's GPU: about 7 seconds a turn, 2–3 minutes an episode. The same model snapshot as the cloud runs, so results compare like for like.

Queue

A job queue on the Mac accepts only allow-listed experiment commands, so the agent can launch and correct runs on its own. A health monitor flags echo, letter bias, runaway loops, dead probes and stalls.

Record

Every run is logged with its code version, command, model revision and data checksums. A dated devlog explains each decision and fix.

Next

Where it goes from here

  • Tonight: 56-episode pilot across twelve conditions, then rerun the closed-loop conditions with the fixed feedback rule.
  • Redesign the action question so it can move: a rating scale instead of a forced choice.
  • Full runs: five scenarios, two framings, four repeats per condition.
  • Repeat the key conditions on a bigger model (Gemma 3 4B) to see which effects survive scale.
  • Persistence: carry a short "body diary" between episodes and test whether self-beliefs consolidate, the developmental part of the ISA paper.

Findings here are functional: they describe internal states and how they drive behaviour. They say nothing about whether anything is felt.
